# Agentic Fruit Detection

A Raspberry Pi 5 camera project using Camera Module 3, a physical push button, and an LED.

## Features

- Capture photos using a physical button
- LED capture indicator
- Timestamped photo filenames
- Raspberry Pi Camera Module 3 support

## Hardware

- Raspberry Pi 5
- Camera Module 3
- Push button
- LED
- 220 or 330 ohm resistor
- Breadboard and jumper wires
